# Xcode Interface Panels Summary

## Navigator

This panel is on the left hand side, the vertical sidebar. There are multiple tabs, from left to right:

- The navigator view (file hierachy for the project)
- Source control navigator
- Bookmarks
- Search function (Find Navigator), so you can search your project with specific text
- Issue Navigator, this shows compiler warnings and errors
- Test Navigator, that can execute unit tests, and can monitor metrics like memory usage, performance
- Debug Navigator, allows you to display active threads, and can help with tracking down bugs in your app
- Breakpoint Navigator lets you view, navigate and manage the breakpoints set across your project
- Report Navigator shows logs, build reports, test results, etc.

## Editor

This is the central panel, where code can be read and written.

## Inspector

On the righthand sidebar, there is a preview window that can show live updates (if you are viewing the swift ContentView).

## Debug Area

The bottom panel splits into the console and the variables view. So it shows live values of variables (if debugging with breakpoints in the code). The lefthand side shows the variables, the righthand side is the console view.

## Toolbar

This is the very top menu, that has the stop/start buttons, the scheme selector, and more to the righthand side, it shows the status indicators for build, ready, etc. There is also an Xcode cloud icon.
