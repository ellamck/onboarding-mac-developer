# Finder Tricks

15 Finder Tricks & Shortcuts

1. Jump to any path: when in Finder, `⌘ + Shift + G` opens a pop-up to type a pathname directly. This supports tab completion and ~ for home.
2. Batch rename files: select multiple files -> right-click -> choose Rename.
3. Create a new folder from a selection: select your files -> right-click -> choose new folder from selection.
4. Open a folder in a new tab: hold `⌘` while double-clicking a folder to open it in a new Finder tab instead of a new window.
5. Add apps/folders to the Finder toolbar: hold `⌘` and drag an app or folder onto the Finder toolbar for quick access.
6. Reveal a folder's file path: right-click the folder name in the title bar or go to View > Show Path Bar for a permanent path bar.
7. Change a folder's icon: copy an image -> select the folder -> Get Info -> click the folder icon -> paste.
8. Lock a file: select a file -> `⌘ + I` -> check "Locked".
9. Turn a file into a reusable template: select a file -> Get Info -> check "Stationery Pad", so opening it always creates a copy instead of editing the original.
10. Show the hidden Library folder: in your Users folder, press `⌘ + J` -> check "Show Library Folder".
11. Quick Look slideshow mode: select multiple files and press ⌥ + Space to preview them as a full-screen slideshow.
12. Toggle hidden files: `shift + ⌘ + .` shows or hides hidden system files in Finder.
13. Keep folders and files sorted separately by name: in Finder Preferences (`⌘ + ,`) -> Advanced tab -> check "Keep folders on top" when sorting by name.
14. Use Quick Actions: select one or more files -> right-click -> Quick Actions to run tasks.
15. Create Smart Folders: file > New Smart Folder, then define search criteria to auto-populate a folder with matching files from anywhere on your system.
16. New Finder Window: `⌘ + N`
17. New Folder: `shift + ⌘ + N`
18. Show Inspector: `⌥ + ⌘ + I`
