# MacOS Keyboard & Productivity Shortcuts

I took the keyboard shortcuts from: https://support.apple.com/en-au/102650

1. cmd + A: Select all items (if you are in a directory, selects all items in that directory, in a document, it will select all the text)
2. cmd + F: Find items in a document or in a Finder window
3. cmd + G: Find the next occurrence of the item previously found
4. shift + cmd + G: Find the previous occurrence of the item found
5. cmd + Q: Quit the current app
6. control + command + Q: Lock your screen
7. control + O: Insert a new line after the insertion point
8. Option key while double-clicking: Open the item in a separate window and close the original window
9. cmd + N: Open a new Finder window
10. control + P: Move up one line
11. cmd + B: Boldface the selected text
12. control + E: Move to the end of a line or paragraph
13. Hold power button to force Mac to turn off
14. cmd + Delete: Moves the selected item to the trash
15. cmd + U: Underline the selected text
16. Fn + A: Show or hide the Dock
17. shift + cmd + D: Open desktop folder (in Finder)
18. shift + cmd + -: Decrease the size of the selected item (in a browser window, this shrinks the text)
19. cmd + K: Add a web link
20. shift + cmd + delete: Empty the trash
