# Activity Monitor Overview

## Verifying if a process actually stopped

You can search in the Activity Monitor for the process, to see if it is still running or not. If the process isn't listed, it successfully stopped.

## When an app stops responding

You can force the application to quit in Activity Monitor, and view the Disk and Network tabs to see the activity to confirm if something is still working or if it is truly frozen.

## If my Mac is slow

You can navigate to the CPU tab and view the percentage of the CPU that a process or app is using. If an app or process is consuming a lot of CPU and it doesn't normally, that can help you debug and figure out which process is the malfunctioning.

## Monitoring memory use

The memory tab can help you monitor if your development has a memory leak, or if a process or application is using the expected about of memory.

## Network monitoring

The network tab allows you to see sent bytes and sent packets, and it could help with figuring out security issues. For instance if an application is sending data when I expected it to be terminated, I could investigate it further through the Activity Monitor.
