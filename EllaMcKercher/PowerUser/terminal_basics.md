# Terminal Commands Explained

1. `pwd` This prints the working directory.
2. `ls` This lists the files and folders in the directory you are in.
3. `cd` Change directory.
4. `mkdir` Creates a new folder. `mkdir -p parent-folder/child`
5. `touch` Creates an empty file.
6. `rm` Deletes a file, there is no undo from the terminal.
7. `cp` Copies a file or folder to a new location `cp -r folder1 folder2` copies folder1 to folder2.
8. `cat` Concatenate: displays a file's full contents in the terminal.
9. `mv` Moves a file or folder to a new location `mv notes.md archive/notes.md`
10. `clear` Clears everything shown in the terminal.
