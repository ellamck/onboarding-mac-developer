## 5 Useful Homebrew Packages

1. **mas**: Apple Store command line interface

– This package lets you install and update App Store apps from the terminal.

2. **bat**: Essentially `cat`

- This package is essentially `cat` that adds syntax highlighting and line numbers.

3. **gh**: GitHub CLI

- This package lets you create pull requests, check CI status, and manage issues directly from the terminal instead of switching to the browser. I already had this installed and use it daily.

4. **wget**: Download files from internet via command line

- This package allows you to download files from the internet through the command line.

5. **tree**: Display folder structure like a tree

- This package lets you display a folder's structure as a visual tree in the terminal. I find this helps when working in the terminal, as sometimes you just need a visual explanation.
